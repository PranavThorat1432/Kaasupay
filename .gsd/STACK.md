## Configuration

| Variable | Purpose | Location | Required |
|----------|---------|----------|----------|
| `PORT` | Backend HTTP port (default: 3000) | `kaasupay-backend/.env` | No |
| `MONGO_URL` | MongoDB connection URI (must support replica sets) | `kaasupay-backend/.env` | Yes |
| `JWT_SECRET` | Secret key for signing and verifying JWT tokens | `kaasupay-backend/.env` | Yes |
| `ADMIN_KEY` | Secret key for staff/admin endpoints (`x-admin-key`) | `kaasupay-backend/.env` | Yes |
| `CLIENT_URL` | Frontend origin for CORS whitelist (default: `http://localhost:5173`) | `kaasupay-backend/.env` | No |
| `RAZORPAY_KEY_ID` | Razorpay public key ID | `kaasupay-backend/.env` | Optional in mock tests |
| `RAZORPAY_KEY_SECRET` | Razorpay private secret for checkout signature verification | `kaasupay-backend/.env` | Optional in mock tests |
| `RAZORPAY_WEBHOOK_SECRET` | Secret for HMAC verification of gateway webhook events | `kaasupay-backend/.env` | Optional in mock tests |
| `BANK_URL` | Upstream partner bank API endpoint (default: `http://localhost:4000`) | `kaasupay-backend/.env` | No |
| `ENCRYPTION_KEY` | 32-byte hexadecimal key for AES-256-GCM bank account encryption | `kaasupay-backend/.env` | Yes |
| `VITE_API_URL` | Backend API base URL consumed by Axios client | `kaasupay-frontend/.env` | No |
| `VITE_RAZORPAY_KEY_ID` | Razorpay public key ID for checkout script | `kaasupay-frontend/.env` | No |
